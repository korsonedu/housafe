The Product · 产品
05 / 15
HOW IT WORKS

全屋雷达组网，无感守护

子女带回家，一人操作、15 分钟装完、无需工具。雷达 7×24 采集，云端 AI 识别异常，异地子女第一时间知道；老人不穿戴、不操作、无感被守护。
01 采集
毫米波雷达组网
Φ85mm 白色感应器，外观像烟雾探测器；天花板/墙壁磁吸，2.4G WiFi 直连云，功耗<2W；采集姿态、活动、呼吸、心率。
02 感知
云端 AI 点云理解
原始点云上云，GPU 自研点云模型，识别跌倒、长时间静止、生命体征异常、日常模式偏离四类事件。
03 判决
延迟确认降误报
跌倒初判后等 3–5 秒观察后续行为 + 多雷达交叉 + 个人基线，区分真摔与快速坐下/蹲下。
04 通知
分级触达子女
不提 / 推送 / 强推+短信 / 电话四级；紧急事件（跌倒）同时短信与电话。
六大核心场景 ｜ S1 浴室跌倒强推 · S2 蹲下捡物不误报 · S3 卧室静止超时提醒 · S4 连续 3 天活动量<基线 50% 建议关注 · S5 首页"昨夜睡眠 7.2h、起床 6:40 状态正常" · S6 导出 30 天趋势 PDF 供医生参考
硬边界 ｜ 无摄像头/无视频 · 不做医学诊断 · 不做 120 调度 · 不测血压/血氧/血糖
The Core Tech · 自研点云感知
06 / 15
THE CORE TECH

从点云到理解，全链路自研

成品雷达模块在固件里算完，只输出"跌倒/未跌倒"这类终点判断，把中间数据丢掉了。长期健康追踪要的恰恰是这些中间数据——我们不买"答案"，直接拿"原材料"。
成品固件
嵌入式 DSP · 输出终点判断 · 丢弃中间数据 · 受功耗约束 · 出厂即定型，精度停在出厂那天。
家安点云
原始点云上云 · 云端 GPU 深度时序模型 · 保留全维度信号 · 算法容量不受限 · 随标注数据持续进化。
从同一条点云流提取 6 类信号
姿态序列 ← 空间分布 → 跌倒初判/基线
速度分布 ← 径向速度 → 精细活动量化
点云形变 ← PCA/质心 → 真摔 vs 坐下
微多普勒谱 ← 相位时频 → 步态参数(P2)
生命体征 ← 胸腔微动 → 呼吸/心率
活动片段 ← 时序聚类 → 基线时间分布
技术门槛：点云极稀疏(每帧 10–50 点)、多径鬼影、微多普勒模糊、无纹理——现有 3D 深度学习不能直接搬，需雷达信号处理 + 点云深度学习跨学科团队。

The Moat · 为什么难复制
08 / 15
WHY US

壁垒：自研的三层软件

LAYER 01 · 感知层
自研点云→跌倒
真正的算法壁垒。门槛不在姿态分类，而在积累跨场景、跨时长的点云标注数据 + 跨学科团队——这两样花钱短期难复制。
算法壁垒
LAYER 02 · 聚合层
多雷达数据聚合
产品/架构壁垒。把 N 条独立时间线拼成同一老人的全屋行为序列、空间拓扑自学习、跨房间追踪；独立模块的架构不支持跨设备关联。
架构壁垒
LAYER 03 · 分析层
个人基线 + 融合
时间壁垒。14 天学出个人常态，以偏离自身基线判断；新进入者上线前 14 天无基线可用，用得越久切换成本越高。
时间壁垒 · 越用越准
数据飞轮：用户越多、用得越久 → 标注数据与个人基线越丰富 → 模型越准 → 体验越好 → 用户越多。壁垒随使用复利加深，而固件方案停在出厂那天。

Competition · 竞争格局
11 / 15
THE WHITE SPACE

C 端全屋买断，是一片空白

价格与形态是最强差异点：子女买给父母、15 分钟自装的 C 端全屋雷达套装几乎没有对手。
现有玩家
固件 · 出厂即定型
萤石/点可/森思泰克用雷达厂商固件，嵌入式 DSP 精度停在出厂那天，用户反馈"误报多、后来就不看了"。
渠道错位
B 端项目 / 绑装修
雷达厂商走 B 端项目制，小米做智能家居非康养，华为绑全屋装修，缺一个消费级、能自己装的产品。
家安差异
自研点云 · 越用越准
云端深度模型持续进化 + 个人基线 + C 端买断零售，三点同时补缺口。
海外对标均为"硬件+月费+B 端"（Vayyar Care $250+$20/月、估值约 $1B；CarePredict $169+$30/月；SafelyYou 纯 B 端）；Apple Watch 纯 C 端但 65+ 佩戴率低、夜间/洗澡失效——室内无感覆盖仍是雷达独占。
