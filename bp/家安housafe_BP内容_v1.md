## 第 5 页 · 产品
- 【版式】四步流水线 + 底部硬件规格/价值行
- 【主题】light
- kicker：THE PRODUCT · 怎么工作
- 标题：全屋雷达组网，无感守护
- lead：专为独居老人设计。子女带回家，一人操作、15 分钟装完、无需工具。雷达 7×24 采集，云端 AI 识别异常，异地子女第一时间知道；老人不穿戴、不操作、无感被守护。系统检测到长期两人同住时自动降级为基础报警模式。
- 四步：
  1. 采集 · 毫米波雷达组网｜Φ85mm 白色感应器，外观像烟雾探测器（对老人称"自动感应开灯的"）；天花板/墙壁 3M 磁吸，2.4G WiFi 直连云，功耗<2W；采集姿态、活动、呼吸、心率。
  2. 感知 · 云端 AI 点云理解｜原始点云上云，GPU 自研点云模型，识别跌倒、长时间静止、生命体征异常、日常模式偏离四类事件。
  3. 判决 · 延迟确认降误报｜跌倒初判后等 3–5 秒观察后续行为 + 多雷达交叉 + 个人基线，区分真摔与快速坐下/蹲下。
  4. 通知 · 分级触达子女｜不提 / 推送 / 强推+短信 / 电话四级；紧急事件（跌倒）同时短信与电话。
- 核心场景（6 个）：S1 浴室跌倒强推；S2 蹲下捡物不误报；S3 卧室静止超时提醒；S4 连续 3 天活动量<基线 50% 建议关注；S5 首页"昨夜睡眠 7.2h、起床 6:40 状态正常"；S6 导出 30 天趋势 PDF 供医生参考。
- 底部核心价值：无感 · 准 · 有预判 · 不骚扰。硬边界：无摄像头/无视频、不做医学诊断、不做 120 调度。

## 第 6 页 · 技术 · AI 感知管线（新）
- 【版式】双栏对比（固件 vs 家安）+ 下方"从点云提取什么"列表
- 【主题】dark
- kicker：THE CORE TECH · 自研点云感知
- 标题：从点云到理解，全链路自研
- 核心论点段：成品雷达模块在固件里算完，只输出"跌倒/未跌倒"这类**终点判断**，把中间数据丢掉了。长期健康追踪要的恰恰是这些**中间数据**——所以我们不买"答案"，直接拿"原材料"。
- 左栏（成品固件）：嵌入式 DSP · 输出终点判断 · 丢弃中间数据 · 受功耗约束 · 出厂即定型，精度停在出厂那天。
- 右栏（家安点云，蓝色强调）：原始点云上云 · 云端 GPU 深度时序模型 · 保留全维度信号 · 算法容量不受嵌入式限制 · 随标注数据持续进化。
- 从同一条点云流提取 6 类信号：
  - 姿态序列 ← 点云空间分布 → 跌倒初判、行为模式、基线
  - 速度分布 ← 每点径向速度 → 精细活动量化（日均速度、快速移动占比）
  - 点云形变 ← PCA 形态/质心轨迹 → 区分真摔与可控坐下
  - 微多普勒谱 ← chirp 相位时频 → 步态参数（步速/步幅/对称性，Phase 2）
  - 生命体征 ← 胸腔微动相位 → 呼吸率、心率（点云副产品，无需单独模组）
  - 活动片段 ← 时序聚类切分 → 个人基线时间分布（何时起床/活动/午休）
- 技术门槛 → 工程解法：
  - 点云极稀疏（每帧 10–50 点，LiDAR 数万点）→ CFAR 前 Range-Doppler / Range-Azimuth 热图 + 滑窗聚合 10–30 帧
  - 多径鬼影 → 多目标跟踪门控 + 静态环境建图剔除
  - 微多普勒模糊 → STFT 时频谱当步态签名直接建模
  - 无颜色纹理 → RCS / 径向速度 / 时序运动特征替代外观
  - 门槛落点：跨户型泛化 · 安装标定鲁棒性 · 自建标注数据集 · 雷达信号处理 + 点云深度学习跨学科团队

- 【版式】三层色块 + 底部数据飞轮
- 【主题】dark
- kicker：THE MOAT · 为什么难复制
- 标题：壁垒：自研的三层软件
- 三层：
  - LAYER 01（蓝色）· 感知层 · 自研点云→姿态→跌倒｜真正的算法壁垒。门槛不在姿态分类，而在积累跨场景、跨时长的点云标注数据 + 跨学科团队——这两样花钱短期难复制。
  - LAYER 02 · 聚合层 · 多雷达数据聚合｜产品/架构壁垒。把 N 条独立时间线拼成同一老人的全屋行为序列、空间拓扑自学习、跨房间追踪；独立模块的架构不支持跨设备关联。
  - LAYER 03 · 分析层 · 个人基线 + 多信号融合｜时间壁垒。14 天学出个人常态，以偏离自身基线判断；新进入者上线前 14 天无基线可用，用得越久切换成本越高。
- 底部数据飞轮：用户越多、用得越久 → 标注数据与个人基线越丰富 → 模型越准 → 体验越好 → 用户越多。壁垒随使用复利加深，固件方案停在出厂那天。
- 能力归属：传感器 = 供应商（commodity）；感知/聚合/分析/决策/交互 = 家安自研。

- 底部单位经济：早期（BOM 425）LTV 232 / CAC 300 = 0.77 承压 → 国产 SoC 降本后（BOM 110）LTV 547 / CAC 250 = **2.19** 转正。第二曲线：沉淀的居家健康数据向保险/养老机构/医疗 B 端变现。
