## 第 5 页 · 产品
- 【版式】四步横排 + 底部场景
- 【主题】light
- kicker：HOW IT WORKS
- 标题：全屋雷达组网，无感守护
- lead：子女带回家，一人操作、15 分钟装完、无需工具。雷达 7×24 采集原始点云，云端 ELPD 世界模型持续理解老人状态，异常分级通知异地子女。老人不穿戴、不操作——这才是老人真正会用的产品。系统检测到长期两人同住时自动降级为基础报警模式，核心健康监测聚焦独居。
- 四步：
  1. 采集｜毫米波雷达组网：Φ85mm 白色感应器，外观像烟雾探测器（对老人称"自动感应开灯的"）。天花板/墙壁磁吸安装，2.4G WiFi 直连云，功耗 < 2W。采集姿态、活动、呼吸、心率。
  2. 感知｜ELPD 世界模型 · 隐空间理解：原始点云 WiFi 直传云端，Encoder 压缩为统一隐空间表征 S_t，Predictor 学习老人行为动力学、预测下一时刻状态。同一隐空间同时产出六类信号，识别跌倒/长时间静止/生命体征异常/日常模式偏离四类事件。
  3. 判决｜Predictor 预测偏差 · 延迟确认：跌倒初判后等 3–5 秒观察后续行为，多雷达交叉验证。Predictor 对比"预测状态"与"真实状态"——预测偏差即异常信号，结合个人基线区分真摔与快速坐下/蹲下。厂商固件没有隐空间表征，无法做预测对比。
  4. 通知｜分级触达子女：不提 / 推送 / 强推+短信 / 电话四级。紧急事件同时短信与电话。
- 六大场景：S1 浴室跌倒强推 · S2 蹲下捡物不误报 · S3 卧室静止超时提醒 · S4 连续 3 天活动量 < 基线 50% 建议关注 · S5 首页"昨夜睡眠 7.2h、起床 6:40 状态正常" · S6 导出 30 天趋势 PDF 供医生参考
- 硬边界：无摄像头/无视频 · 不做医学诊断 · 不做 120 调度

## 第 6 页 · 技术架构（核心深度页）
- 【版式】双栏对比（管道 vs 世界模型）+ 底部验证数据 + 硬件演进
- 【主题】dark
- kicker：THE CORE TECH
- 标题：从管道到世界模型——架构代际差异
- 核心论点：成品雷达模块在固件里算完，只输出"跌倒/未跌倒"这类终点判断，中间数据全部丢弃。长期健康追踪需要的恰恰是这些中间数据。所以我们不买"答案"，直接拿"原材料"——原始点云上云，跑自己的模型。
- 左栏（传统管道 · 竞品架构）：
  - 传感器 → 姿态分类 → 事件合并 → 状态机 → 基线统计 → 偏离检测 → 融合打分 → 通知路由
  - 各模块独立输出离散标签，信息在每一步被硬决策丢弃
  - "跌倒 + 浴室"只是两个字符串，没有空间上下文
  - 规则冲突无法自我修复（"静止 30 分钟报警"在老人睡觉时触发）
  - 新功能 = 新模块 + 新接口 + 新标注数据
- 右栏（ELPD 世界模型 · 家安，蓝色强调）：
  - Encoder 压缩原始信号 → 隐空间 S_t（唯一真相源）→ Predictor 学习状态演化 → Decoders 翻译为任务输出
  - 所有信号在同一个隐空间中自然耦合——位置和姿态在同一个向量空间，"躺浴室地上"和"躺床上"天然可区分
  - 自监督学习：每个正常日子都是训练数据，不需人工标注
  - 预测偏差 = 异常信号：系统觉察"现实与预期不符"——这是规则引擎做不到的
  - **就像 OpenAI 用 GPT 替代 N 个 NLP 模型，家安用 ELPD 替代 N 个专用检测算法——在居家养老这个场景里。**
- 从同一条点云流提取 6 类信号：姿态序列（空间分布）· 速度分布（径向速度 → 精细活动量化）· 点云形变（PCA/质心 → 区分真摔与坐下）· 微多普勒谱（相位时频 → 步态参数，Phase 2）· 生命体征（胸腔微动 → 呼吸/心率）· 活动片段（时序聚类 → 基线时间分布）
- 技术可行性（行业已验证/参考设计，非产品实测）：
  - 跌倒检测 92%+ 准确率、误报 < 3%（TI IWR6843 参考设计，20㎡；Application Note ZHCAA43）
  - 呼吸 ±0.4 次/分、心率 ±1.0 次/分（安静睡眠；西京学院 2026，n=20）
  - 步态参数预测跌倒风险（Nature Sci Rep 2025 / Frontiers in AI 2024，学术验证阶段）
- 硬件演进（选型看点云质量 + SDK 开放度）：IWR6843ISK 开发板（攒数据）→ TI 模组 ~200 元 → 自研一体板 ~100 元（量 > 5000）→ 国产 60GHz SoC ~60 元（量 > 5 万，首选加特兰）
- 诚实备注：自研点云模型精度是 MVP 最核心的技术风险。开发期并行跑固件作对照基准，不达预期则先用固件过渡、自研并行。

## 第 7 页 · 护城河
- 【版式】三层色块纵向堆叠 + 底部数据飞轮
- 【主题】dark
- kicker：THE MOAT
- 标题：三层壁垒：范式、算法、时间
- 说明段：壁垒不在传感器（传感器是供应商的通用件），也不在单个算法（算法可以复现）。真正的壁垒是三样东西的叠加——架构范式的代际差异、跨学科团队的稀缺性、以及随时间复利加深的数据资产。
- 三层：
  - LAYER 01（蓝色）· 范式壁垒 · 统一隐空间世界模型：传统养老监测是一条管道——传感器到规则到事件到通知，每层做硬决策、丢信息。ELPD 用一个隐空间统一表征所有信号，多维度偏离在隐空间中自动耦合。竞品从管道迁移到世界模型，要改的是公司架构，远不止代码。
  - LAYER 02 · 算法壁垒 · 自研点云 Encoder：毫米波雷达点云极其稀疏（每帧 10–50 点，LiDAR 是数万点）、噪声特殊（多径鬼影、微多普勒模糊）、无颜色纹理。需要同时懂雷达信号处理 + 点云深度学习 + 自监督表示学习的团队。竞品要么用厂商固件（硬件厂），要么用视觉模型搬过来（AI 厂但回避了雷达信号）。
  - LAYER 03 · 时间壁垒 · 数据飞轮 + 个人基线：自监督学习零标注成本——每个正常日子都是训练信号。14 天建立个人基线，3 个月比 14 天准，1 年比 3 个月准。用得越久切换成本越高——固件精度停在出厂那天，世界模型每天都在进化。
- 底部数据飞轮：用户越多 → 数据越丰富 → 模型越强 → 产品越好 → 用户更多。飞轮一旦转起来，追赶需要的不只是钱，是时间。

  - 家安（蓝色）· 世界模型 · 越用越准：云端深度模型持续进化，自监督学习让模型随数据积累变强——固件做不到这一点。加上个人基线和 C 端买断零售，三点同时补空白。
- 底部海外对标：Vayyar Care $250/台+$20/月（估值约 $1B）；CarePredict $169+$30/月；SafelyYou 纯 B 端。三家都是"硬件+月费+B 端"模式。Apple Watch 纯 C 端买断但 65+ 佩戴率低、夜间充电/洗澡取下。室内无感覆盖仍是雷达独占场景。
